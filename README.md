# 五岔路口交通管理系统

一个可在浏览器直接运行的五岔路口信号控制演示。项目将路口的 **13 条可通行路线** 建模为互斥/兼容关系，并按车辆等待量动态选择一组可同时放行的路线。

## 路口建模

道路 C 为单行离开路口，E 为单行进入路口；A、B、D 为双向道路。因此：

| 入口 | 合法出口 | 路线数 |
|---|---|---:|
| A | B、C、D | 3 |
| B | A、C、D | 3 |
| D | A、B、C | 3 |
| E | A、B、C、D | 4 |
| **合计** |  | **13** |

例如，`E→B` 与 `A→D` 的行驶轨迹在路口中心冲突，不能同时给绿灯；`A→B` 与 `E→C` 不相交，可以同时放行。

## 控制方法

1. 对每条路线绘制穿越路口的轨迹，并自动生成冲突矩阵：同一入口、同一出口或轨迹过近的两条路线均互斥。
2. 每 6 秒进入一次配时决策。控制器以各路线等待车辆数为权重，使用贪心最大权重独立集方法，挑选一组不冲突的路线作为绿灯相位。
3. 采用“黄灯 2 秒 → 全红 1 秒 → 新相位绿灯”的安全切换；绿灯期间按固定通行能力消化排队车辆。
4. 对长期未放行的路线增加等待时长权重，避免饥饿。

这不是道路工程的最终配时方案；实际部署还应接入检测器、行人相位、救护车优先及完整的安全审查。

## 运行

无需安装任何软件：双击打开 `index.html`，或将整个目录部署到 GitHub Pages。

在页面中可点击路线按钮增加车辆，或打开“自动来车”。画面会显示当前信号状态、绿灯路线、路线队列与控制日志。

git add .
git commit -m "完成五岔路口交通管理系统"
git branch -M main
git remote add origin https://github.com/你的用户名/five-way-traffic-control.git

创建仓库时选择 Public，且不要勾选初始化 README（本项目已有 README）。提交后，将仓库链接粘贴到智慧树。

## 文件说明

- `index.html`：可运行的交互演示页面
- `app.js`：路线、冲突检测、相位选择和仿真逻辑
- `style.css`：界面样式
- `REPORT.md`：汇报视频可直接照读的讲稿与演示流程
